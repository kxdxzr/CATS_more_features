# CATS More Features v3.2.2

**This fork remains under active testing and may contain bugs.** Scheduled start has been tested in game, but
complete routes, refuelling modes, cooldown recovery, power saving and completion actions need further in-game
testing. Run supervised tests before relying on unattended operation.

## Download

Download the Windows x64 ZIP below, extract it to a writable folder, and run `CATS-new.exe`. Requires 64-bit
Windows and .NET Framework 4.7.2 or later; Python is bundled. See `START_HERE.txt` and `README.md` in the ZIP.

## Highlights

- Scheduled start with calendar, time selectors and shortcuts.
- Route completion actions: keep open, close the game and CATS, or request computer shutdown.
- **Test refuel...** executes one refuelling input sequence without starting a route or completion action.
  It sends real game inputs and can move cargo even when automatic refuelling is disabled. Manually verify the result.
- Scheduling controls stay aligned with the route editor when the window is resized.
- Journal-based pending-jump/cooldown recovery and saved route position.
- Updated personal carrier transfer sequence; squadron sequence is unchanged.

## Safety and limitations

- Stop cancels CATS automation, not a jump already submitted in-game. A previous onefile packaging regression
  could leave a child process running; the fix has automated coverage but needs more in-game validation.
- The game-close action may terminate the game after 15 seconds. Shutdown has a 30-second Windows countdown;
  use `shutdown /a` to cancel it.
- Fuel transfer and different carrier modes remain unverified in full. A completed test sequence does not
  confirm that fuel moved. Stop, cooldown recovery and completion actions may have bugs.
- The packaged defaults keep the game open, do not schedule shutdown, and have an empty route and webhook.
- Frontier API login requires your own registered client ID; journal-based traversal does not.

Automated checks cover journal handling, stop/restart process management, UI layout and mock completion/refuelling
logic. They do not send game inputs or perform real game exits or shutdowns.

Report issues at https://github.com/kxdxzr/CATS_more_features/issues. Thanks to the original CATS authors.
