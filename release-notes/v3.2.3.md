# CATS More Features v3.2.3

This build may contain bugs. Hardware support and game state can vary; supervise operations and check
refuelling and display behaviour on your setup before relying on unattended operation.

## Changes

- The experimental warehouse extraction guard stops further extraction for the current run after
  detecting non-tritium. If a transfer cannot be identified, the Options setting selects whether to
  stop further extraction (default) or ignore it. It also compares before/after `Cargo.json` snapshots
  where `CargoTransfer` events are absent, including some squadron-carrier scenarios.
- Optional hardware brightness reduction lasts from the start of the route, including scheduled waits,
  until completion, Stop or a catchable error. A separate option requests display power-off after closing
  the game and CATS; it does not request computer sleep. Both options default off.
- Waiting for an existing carrier jump, cooldown and scheduled start now updates the existing countdown
  label rather than repeatedly appending to the log. Old uncompleted requests are ignored when their
  scheduled departure is over 30 minutes old.
- When a pre-existing jump is confirmed to have arrived, automatic refuelling is enabled and the Journal
  provides the necessary request and arrival records, CATS attempts refuelling during cooldown.

## Important limitations

- Cargo detection occurs **after** transfer and cannot prevent or reverse the first mistaken extraction.
  Snapshot changes do not prove their source; do not manually transfer cargo during automated operations.
  Mixed-cargo depot behaviour and the new squadron fallback require further in-game testing.
- Journal records may not expose jumps planned by another commander. Missing requests are treated as no
  planned jump; a very delayed request can be ignored after the 30-minute threshold. Invalid departure
  times remain waiting for confirmation.
- Display control depends on hardware and drivers. Some screens do not support it. Power loss, forced
  termination or driver problems can prevent brightness restoration. Windows or input can wake displays.
- Stop does not cancel a jump already submitted in game. Test all features while present before relying on them.

The Windows ZIP is a portable installation. Extract it to a writable folder; keep backups of existing
settings and routes. The package uses repository defaults and does not contain local settings or logs.
